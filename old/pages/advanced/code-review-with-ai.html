Code Review with AI

AI can improve review coverage, but it does not replace accountable review by people who understand the system and its risks.

Expertise: Advanced Audience: Reviewers and technical leads Use when: Reviewing technical changes Version: 1.0

Who this is for

This guide is for developers, QA, security reviewers, and leads using AI to widen review coverage without outsourcing judgment.

What you will learn

  • How to ask AI for useful review angles.
  • Where AI review differs from human review.
  • How to handle false positives and false negatives.

Useful AI review angles

Bugs

Ask what behavior could fail under normal use.

Edge cases

Ask what inputs, states, concurrency, or dependencies were missed.

Security

Ask for auth, injection, exposure, logging, and permission concerns.

Maintainability

Ask whether the change fits existing patterns and naming.

Test gaps

Ask what tests would fail if the change is wrong.

Human review

Ask which parts need accountable reviewer attention.

Good use and risky use

Good use

Use AI to generate review questions, identify likely gaps, and compare risks, then verify findings against the diff, tests, and system context.

Risky use

Accept AI review comments as authoritative, ignore human reviewer expertise, or dismiss missing findings because AI did not mention them.

Try this prompt

Use this with a focused diff and relevant context.

Review this diff for bugs, missed edge cases, security issues, maintainability concerns, and test gaps. Separate likely issues from speculative questions. Call out false-positive risk. List what a human reviewer should verify before approval.

Review checklist

Diff: Did AI inspect the actual change, not just the summary? Evidence: Are findings tied to lines, behavior, or tests? Coverage: Did it check bugs, security, maintainability, and tests? False positives: Were speculative findings verified before action? False negatives: Did humans still perform accountable review?

Key takeaway

AI is a useful second reviewer, not a final approver. It can add angles, but people own the review decision.
