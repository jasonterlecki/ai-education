Blast Radius Thinking

Before using AI on real work, ask what can break, who can be affected, how quickly you would know, and how you would recover.

Expertise: Intermediate Audience: Team leads and AI workflow owners Use when: You need to size risk before acting Version: 1.0
Back to index Previous: Review Gates

Who this is for

This guide is for anyone deciding how much review, planning, validation, or approval an AI-assisted task needs.

What you will learn

  • How to ask what can break before using AI.
  • How different work types carry different consequences.
  • How blast radius changes the workflow you should choose.

Ask what can break

Blast radius is the potential impact if AI-assisted work is wrong, incomplete, insecure, or misunderstood. It includes affected users, systems, data, money, reputation, compliance, and recovery effort.

Low blast radius work can move faster. High blast radius work needs planning, review gates, validation, approvals, and rollback.

Examples

Task Likely blast radius Safer workflow
Harmless document draft Low if reviewed before sharing AI draft plus human review
Customer-facing page Medium to high Content review, accessibility check, source verification, rollback path
Database migration High Plan, backup, dry run, staged execution, rollback instructions
Terraform or IAM change High Plan, least-privilege review, dry run, approval, audit trail
Production incident response High and time-sensitive Use AI for options only; accountable responders decide and act
Payment flow Critical Formal change control, tests, monitoring, rollback, approval
Regulated data workflow Critical Approved tools, policy review, access control, audit trail

Good use and risky use

Good use

Classify blast radius before prompting, choose a workflow that matches the risk, and escalate when users, money, data, security, or production safety are involved.

Risky use

Treat all AI tasks the same, using the speed of a document draft for database, IAM, payment, incident, or regulated-data changes.

Try this prompt

Use this before choosing an AI workflow.

Assess the blast radius of this task: [task]. Consider users, systems, data, money, security, compliance, reputation, and recovery. Return: 1. Blast radius level: low, medium, high, or critical. 2. What could break. 3. Who could be affected. 4. Required review gates. 5. Validation and rollback needed before acting.

Key takeaway

The higher the blast radius, the more control you need. AI speed is useful only when matched with the right planning and review.
