Context and Prompt Drift

AI sessions drift as context grows, corrections pile up, and assumptions go stale. Learn when to restate rules or start fresh.

Expertise: Intermediate Audience: Frequent AI users and workflow leads Use when: A session is getting long or inconsistent Version: 1.0
Back to index Previous: Checkpointed Execution Next: Plans and Specs

Who this is for

This guide is for users who run longer AI sessions, iterate through corrections, or ask an AI agent to work across multiple files or decisions.

What you will learn

  • How context bloat weakens focus.
  • Why repeated corrections can still be forgotten.
  • When durable repo instructions or a fresh session help.

How sessions drift

Context bloat

Too many old details compete with the current task.

Forgotten constraints

Early rules become less visible as the session grows.

Repeated corrections

The model may comply once, then drift back later.

Stale assumptions

Facts from earlier work may no longer match the current state.

Contradictory instructions

Old and new requests can point in different directions.

Unclear stopping point

The agent may continue beyond the work you intended.

Good use and risky use

Good use

Restate critical constraints at phase boundaries, keep durable rules in repo instructions, and start a fresh session when the task changes.

Risky use

Keep adding corrections to a long session and assume the AI still remembers scope, file boundaries, approval rules, and current facts.

When to start fresh

  • The goal changed from exploration to implementation.
  • The AI keeps repeating a corrected mistake.
  • The session contains outdated architecture, decisions, or file paths.
  • You need a clean handoff to a new phase.
  • The next task needs different permissions, reviewers, or validation.

Try this workflow

Use this before continuing a long session.

1. Summarize the current goal in one paragraph. 2. Restate non-negotiable constraints. 3. List files or areas that are in scope and out of scope. 4. Ask the AI to identify stale assumptions or contradictions. 5. If the answer is unclear, start a fresh session with the cleaned summary.

Key takeaway

Long sessions are convenient, but they can blur instructions. Durable repo rules and fresh checkpoints keep AI work aligned with the current task.
